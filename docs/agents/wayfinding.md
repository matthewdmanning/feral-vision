# Wayfinding

Use this guide only for a Wayfinder map or child ticket.

- A map has label `wayfinder:map`.
- Children use `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`,
  or `wayfinder:task`.
- Prefer GitHub sub-issues; otherwise use a task list and `Part of #<map>`.
- Record dependencies natively or as `Blocked by: #<number>`.
- The frontier is the first unassigned open child without open blockers.
- Claim by assignment; resolve with a comment, closure, and linked map decision.
